# Todos los caminos conducen al templo
**Las ciudades medievales y el factor religioso (siglos VII–X)**

Página web interactiva sobre la ciudad cristiana y la ciudad islámica en la Edad Media temprana.

- **Autor:** Sebastián Mauricio Delgado Gómez
- **Institución:** Universidad Pedagógica Nacional
- **Asignatura:** Historia de las Sociedades Medievales

## Contenido
- Introducción: por qué explorar las ciudades.
- Ciudad cristiana y ciudad islámica: tarjetas de conceptos desplegables, con textos para profundizar, citas textuales y referencias.
- Comparador interactivo de ocho dimensiones.
- Juego "Ponte a prueba".
- Conclusiones y referencias.

## Cómo verla
- **En local:** abre `index.html` con el navegador (las tipografías medievales necesitan conexión a internet; sin ella se usan fuentes de respaldo).
- **En GitHub Pages:** sube el contenido de la carpeta a un repositorio público (`index.html` e `images/` en la raíz) y activa **Settings → Pages → Deploy from a branch → main / (root)**.
